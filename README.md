# 影之刃零本地存档管理器

Windows PowerShell + WinForms 小工具，支持一键备份、历史快照浏览、恢复前自动备份、SHA256 校验和进度备注。

## 使用

1. 下载整个仓库（Code → Download ZIP），解压到可写文件夹。
2. 双击 `PBZ-Backup-Manager.cmd`。不要只下载启动脚本，配套 `.ps1` 必须在同一目录。
3. 首次启动选择包含 `PBZSaveGame.sav` 的账号文件夹，通常位于游戏安装目录 `ProjectPBZ/Saved/SaveGames/Steam/<账号ID>`。路径保存到本地 `config.json`；换账号时删除该配置再选。
4. 退出游戏后点击“一键备份”，或双击 `Backup-PBZ-Now.cmd`。
5. 恢复时先退出游戏和 Steam，保持游戏云同步关闭。选择历史快照并点击“恢复选中的存档”。恢复前自动保留当前存档。

## 功能与限制

- 自动扫描实时、小时、每日历史文件，以及本工具的备份，按内容去重。
- 可筛选今天以前的快照、添加进度备注；双击条目定位文件。
- 备份保存在工具旁的 `PBZ-Backups`，不会自动清理。
- 可将额外备份文件夹放入工具旁的 `Imported-Backups`。
- 时间是文件快照时间，不一定是游戏内保存时间。暂不解析地点和游玩时长。
- 恢复整份主存档，无法单独合并游戏内某一个槽位。
- SHA256 检查复制完整性，不保证游戏逻辑有效性；恢复后请在游戏中确认。
- 需要 Windows 和 Windows PowerShell 5.1。启动器的执行策略选项只作用于启动进程，不修改系统策略。

仓库不包含个人存档、账号配置或备注。首次公开版本的路径选择由原本固定路径改造而来；备份/恢复核心曾在临时副本上验证，游戏版本兼容性需实际确认。
